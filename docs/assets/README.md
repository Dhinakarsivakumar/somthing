# Proposal Website Assets Guide 💍❤️

Place your personalized media files in this directory (`public/assets/`):

| File Name | Purpose | Description |
| :--- | :--- | :--- |
| `romantic-music.mp3` | Background Music | Romantic soft instrumental/piano music that plays during the experience. If omitted, the website automatically falls back to a gentle built-in ambient harmony synth. |
| `proposal-voice.mp3` | Voice Recording | Your recorded voice saying **"I love you, Maria."** Played at the emotional climax in Scene Six. |
| `necklace.png` | Necklace Jewelry | High-resolution image of Maria's necklace with transparent background. If omitted, a high-detail SVG gold heart pendant is rendered. |
| `heart-ring.png` | First Ring Photo | Maria's heart-shaped ring photo. If omitted, custom animated SVG jewelry is rendered. |
| `proposal-ring.png` | Second Ring Photo | Marriage proposal ring photo. If omitted, custom animated SVG diamond ring is rendered. |
| `maria-photo.jpg` | Maria's Photograph | Optional romantic portrait photo of Maria. |
| `female-hand.png` | Female Hand | Optional custom hand photo. Hand animations are rendered with SVG layers. |
| `male-hand.png` | Male Hand | Optional custom hand photo. Hand animations are rendered with SVG layers. |

## Tips for Best Results:
- **Audio Files**: Use MP3 or AAC format, normalized to -14 LUFS for a warm, comfortable listening experience.
- **Images**: Use PNG format with transparent backgrounds for jewelry (`necklace.png`, `heart-ring.png`, `proposal-ring.png`).
